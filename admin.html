This week's checklist

Open each official source, then tick it off. Ticks are saved in this browser only.

Weekly process

  1. An automated run checks every competitor each Thursday (see WEEKLY_COLLECTION.md).
  2. Also scan X / LinkedIn, TechCrunch, The Information and SemiAnalysis for what blogs miss.
  3. Log product, pricing, GPU, region and partnership moves. Skip hiring, events and pure tutorials.
  4. Every move needs a source URL and one "why it matters for GMI" sentence.
  5. High = hits a core GMI claim or buyer decision. Medium = worth tracking. Low = FYI.
  6. Publish: export data.js and replace the file on the server.
  7. Refresh insights.js monthly, or when a trend shifts.
